# Savegame Renamer - In-Game GUI

Дизайн мода для Kingdom Come: Deliverance II, 17.08.2026.

modid `savegame_renamer`, автор Lefxxx.

## Задача

Переименование существующего сохранения из штатного меню игры, средствами интерфейса
самой игры, без консоли и без внешних утилит.

Существующий мод [Rename Your Savegame](https://www.nexusmods.com/kingdomcomedeliverance2/mods/3488)
(thazer, требует KCSE) решает ту же задачу консольными командами `save_rename <id> <name>`
и `rename_save_list`, причём список сохранений после переименования не обновляется:
автор инструктирует выйти на экран выбора плейлайна и вернуться обратно.

## Проверенные факты

Всё ниже установлено на версии игры `1.5.6-15693-release_1_5` разбором файлов и
экспериментами на живых сохранениях.

### Формат `.whs`

```
FF FF FF FF | int32 length | length байт UTF-8 XML с завершающим NUL | payload
```

Корневой элемент `C_SaveGameDescription`. `length` включает NUL. Payload
самоописателен и не зависит от размера заголовка, поэтому описание можно свободно
растить и сокращать, пересчитав `length`.

### Отображаемое имя

Имя в списке берётся из поля 2 атрибута `UIDescription`, разделитель полей `|`:

```
type | index | questName | objectiveName | location | timestamp | dateStr | playtimeHours
```

Строка, не начинающаяся с `@`, печатается дословно; `@`-строка резолвится как ключ
локализации. Поле 3 подклеивается к имени через « - », пустое поле 3 убирает разделитель
и хвост.

Атрибут `QuestNameOverride` на отображение не влияет: сохранение, у которого изменён
только он, выглядит в списке идентично исходному. Атрибут `m_saveName` внутри
`C_SaveGameDescription` служит ключом поиска по `strcmp`, поэтому не трогается.

### Расширяемость заголовка

Неизвестный игре атрибут корневого элемента разбор переживает: сохранение попадает
в список и загружается. Неизвестный дочерний элемент разбор ломает, сохранение из
списка пропадает. Отсюда: собственные данные хранятся только атрибутами.

### Ввод и кодировка

UTF-8 кириллица в заголовке отображается штатным шрифтом без искажений. Длинное имя
не обрезается и не переносится: строка списка прокручивается по горизонтали.

### Точки входа в игре

Из реверс-инженерных заголовков [libKCD2](https://github.com/JerryYOJ/libKCD2)
(привязаны к `WHGame.dll 1.5.6 (kd7u)`):

- `wh::framework::C_SaveGameManager::m_slotsByType` — списки описаний по типам;
- `C_SaveGameDescription::m_fileName` — имя файла сохранения;
- `UpdateSaveGameDescriptions` — перечисляет `*.whs` и пересобирает списки;
- `wh::guimodule::C_UISaveLoad` — контроллер меню сохранения и загрузки, страница
  списка строится `BuildLoadGamePage`, входящие flash-диспетчеры `OnLoadButton`,
  `OnDeleteLoadButton`, `OnPlaylineButton`.

Часть полей в этих заголовках помечена автором как `UNVERIFIED`; каждое обращение
к ним подпирается проверкой на месте.

### Как игра рисует подсказки клавиш

Разобрано в `Libs/UI/buttons.gfx` и в классах `ActionButton`, `ControlsEnum`,
`TextExtension` из `Menu.gfx`.

`buttons.gfx` — библиотека: на её главной сцене лежит спрайт `mc_button`, кадры
которого названы по клавишам и по плашкам. Три плашки клавиатуры и есть три
кадра, `ControlsEnum` раздаёт их по клавишам вместе с шириной, которую строка
резервирует под плашку при её родной высоте 64:

| Кадр | Текстура | Ширина отрисовки | `E_WIDTH_n` | Кому достаётся |
|---|---|---|---|---|
| `key` | `key.dds` 64×64 | 64 | 52 | буквы, цифры, F1…F12 |
| `escape` | `key_middle.dds` 128×64 | 95 | 83 | Esc, Tab, `NP_*` |
| `enter` | `key_long.dds` 128×64 | 115 | 106 | Enter, Delete, Insert, Space, модификаторы |

В каждом кадре уже лежит поле `tField`: `DefaultFontBold`, кегль 30, чёрный,
выключка по центру. Отсюда и чёрные жирные названия клавиш, и центровка — её
делает выключка поля, а не арифметика.

Потребитель не импортирует ни плашку, ни спрайт: `ActionButton.addButton`
подгружает библиотеку целиком через `MovieClipLoader.loadClip("buttons.swf", …)`,
переводит `mc_button` на нужный кадр, пишет в `tField` и масштабирует спрайт как
`height / 64 * 100`. Размер задаёт `TextExtension.drawButtons`: полторы высоты
знакоместа, которое подсказка заменяет, а центр плашки ставится на середину
строки.

Имя `buttons.swf` — авторское, в паке лежит `buttons.gfx`. Подмены расширения по
дороге не происходит: в лог открытия файла строка приходит как написана, поэтому
мод просит библиотеку по имени, под которым она поставляется.

`renamer.as` повторяет это дословно. Своей плашки у мода нет.

## Архитектура

Нативный плагин под [KCSE](https://www.nexusmods.com/kingdomcomedeliverance2/mods/3332)
плюс собственный элемент Scaleform-интерфейса. Ванильные файлы игры не подменяются,
поэтому конфликтов с другими модами интерфейса нет.

Четыре модуля с непересекающимися зонами ответственности.

### `whs::Description`

Модель. Чистый C++ без зависимостей от игры и от KCSE: читает заголовок `.whs`,
отдаёт и меняет отображаемое имя, пишет файл обратно. Тестируется офлайн на копиях
реальных сохранений.

Правила записи:

- первое переименование складывает исходные поля 2 и 3 в атрибут
  `RenamerOriginal="<questName>|<objectiveName>"`, и только если атрибута ещё нет,
  иначе второе переименование затёрло бы настоящий оригинал;
- поле 2 получает новое имя, поле 3 очищается;
- сброс восстанавливает оба поля из атрибута и удаляет атрибут;
- запись атомарная: временный файл в том же каталоге, затем замена. Сохранение весит
  несколько мегабайт, обрыв записи посреди файла недопустим.

Прототип модели на Python, проверенный на живых сохранениях, лежит в `tools/whs_header.py`
и служит эталоном поведения для портирования.

### `SaveCatalog`

Мост к игре. Достаёт из `C_SaveGameManager` описание нужного сохранения и его
`m_fileName`, после записи вызывает `UpdateSaveGameDescriptions`, чтобы список
перестроился на месте.

### `RenameDialog`

Вид. Собственный элемент интерфейса по образцу MCM из libKCD2: `renamer.gfx` плюс
XML-описание `renamer.xml` с `keyevents="1"`, `mouseevents="1"`, `events_exclusive="1"`
на своём слое поверх меню. Рядом кладутся `gfxfontlib.gfx` и `gfxfontlib_glyphs.gfx`,
без них текст не отрисуется.

Внутри: рамка в стиле ванильного модального окна, `TextField` с `type="input"`,
предзаполненный текущим именем, кнопки принять, отменить, сбросить. Наружу три
события `fscommand`. Модуль не знает про сохранения: получает строку и возвращает строку.

Управление: Enter принимает, Esc отменяет, сброс к оригиналу вынесен кнопкой в самом
диалоге, чтобы не занимать клавишу. Символы ввода доезжают до movie штатными
char-событиями; Enter и Esc форвардятся плагином через `IInputEventListener`, как это
делает MCM.

### `SaveLoadHook`

Склейка. Хук на `C_UISaveLoad`: добавляет подсказку и обработчик клавиши на странице
списка, по нажатию открывает диалог для выделенной строки, по результату вызывает
модель и каталог. Диалог открывается по F2: клавиша свободна в меню и означает
переименование в подавляющем большинстве интерфейсов.

### Поток

Список сохранений, нажатие клавиши переименования, `SaveLoadHook` спрашивает у
`SaveCatalog` имя файла выделенной строки, `RenameDialog` забирает ввод,
`whs::Description` пишет файл, `SaveCatalog` обновляет описания, список
перерисовывается.

## Краевые случаи

| Ситуация | Поведение |
|---|---|
| Пустой ввод | Сброс к оригиналу |
| Символ `\|` во вводе | Вырезается: это разделитель полей `UIDescription` |
| `"`, `<`, `&` во вводе | Экранируются, иначе ломается XML заголовка |
| Имя длиннее 40 символов | Счётчик символов в диалоге подсвечивается, запись не блокируется: вёрстка не ломается, строка прокручивается |
| Сохранение удалено или перезаписано игрой, пока открыт диалог | Перед записью сверяется `SaveId` внутри заголовка, при расхождении запись отменяется |
| Сохранение уже переименовано | `RenamerOriginal` не перезаписывается, доступен сброс |
| Имя набрано письменностью другого языка игры | Хранится как набрано, но рисуется квадратиками, пока активен не тот языковой профиль |

### Почему чужая письменность не рисуется

`Libs/UI/fontconfig.xml` держит пять профилей шрифтов, и каждый тянет свою
библиотеку глифов. Ни в одной нет полного набора для чужой письменности —
посчитано по самим библиотекам:

| Профиль | Библиотека | Kingdom Come Regular | Swei Spring Sugar (Chineses) |
|---|---|---|---|
| `default` (в том числе русский) | `gfxfontlib_glyphs.gfx` | 644 глифа | 4 глифа |
| `chineses` | `gfxfontlib_glyphs_chineses.gfx` | 48 глифов | 21917 глифов |

По четыре глифа на чужую письменность хватает ровно на её название в выборе
языка, и не более. Ограничение обоюдное: под китайским профилем латинский шрифт
урезан до 48 глифов.

Мод здесь бессилен, не таща с собой шрифт: профиль выбирает игра по своему языку,
а `DefaultFont` — это отображение на гарнитуру внутри активной библиотеки.
Само имя не страдает: оно лежит в заголовке как набрано и рисуется правильно,
стоит вернуть язык, которым набрано.

## Вне объёма

Сохранение после сна и квестовый автосейв **сознательно оставляются с именем по
умолчанию**: мод в эти пути не вмешивается вовсе. Это решение, а не пропуск.

Запрос имени прямо в момент ручного сохранения переносится в версию 2 и будет второй
точкой вызова того же диалога: `C_SaveGameManager::CreateSaveGame` уже принимает
параметр имени, а KCSE отдаёт событие `SaveGame`.

## Риски

**Индекс выделенной строки.** Диспетчер `OnLoadButton` даёт индекс нажатой строки,
а диалогу нужна выделенная. Решается либо чтением состояния из flash, либо хуком на
построение страницы. Главная неизвестная реализации, выясняется первым же прогоном
под отладчиком.

**Привязка к версии игры.** Адреса libKCD2 соответствуют текущей сборке, но поедут
при патче. Смягчается зависимостью от
[Address Library For KCSE](https://www.nexusmods.com/kingdomcomedeliverance2/mods/3381).

**Steam Cloud.** Каталог сохранений синхронизируется. Данные о переименовании лежат
внутри самого `.whs`, поэтому переживают синхронизацию и удаляются вместе с сохранением.

## Стек и раскладка

C++20, CMake, KCSE и заголовки libKCD2. Вид на ActionScript 2 (Flash 8, Scaleform GFx),
сборка `.gfx` через JPEXS FFDec. Парсер FFDec ограничен: одно объявление на `var`,
без объектных литералов, без тернарного оператора, без цепочек присваивания.

```
savegame_renamer/
  docs/          спецификация, описание для Nexus, изображения
  flash/         renamer.as, renamer.gfx, renamer.xml, шрифтовые библиотеки
  releases/      savegame_renamer-<version>.zip
  src/
    KCSE/Plugins/    собранная DLL
    Data/            ресурсы интерфейса
    mod.manifest
  tools/         build.py, whs_header.py
```

## Тестирование

Модель тестируется офлайн: набор реальных сохранений, для каждого проверяется цикл
чтение, переименование, чтение, сброс, побайтовое сравнение с исходником. Payload
обязан оставаться неизменным, что проверяется хешем.

Интеграция проверяется в игре: переименование, обновление списка без выхода из меню,
загрузка переименованного сохранения, сброс к оригиналу, ввод кириллицы, ввод
запрещённых символов, отмена диалога.
