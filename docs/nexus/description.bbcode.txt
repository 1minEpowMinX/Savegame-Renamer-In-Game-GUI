[size=6][b]Short description[/b][/size]
Rename any savegame from the game's own load menu. Highlight a save, press F2, type a name. No console, no external tools, and the list updates on the spot.

[size=6][b]The problem[/b][/size]
Your saves are named after the quest that was running when you made them, and nothing else. Play one questline for an evening and the load list turns into six rows reading [i]Quest name[/i], separated only by a timestamp. There is no way to mark the one before the hard fight, the one you want to come back to, or the one you keep for a different ending.

The information you want is already in the file. It just isn't yours to write.

[size=6][b]Main features[/b][/size]
[list]
[*][b]F2[/b] on the highlighted save opens a rename dialog. The key does nothing anywhere else in the game[/*]
[*][b]Enter[/b] accepts, [b]Esc[/b] cancels, [b]Del[/b] puts the original name back. Every prompt is clickable too[/*]
[*]The load list redraws immediately, without leaving the page and coming back[/*]
[*]The original quest name is kept inside the save, so a rename is never one-way[/*]
[*]Built from the game's own artwork: the window frame, the key plates and the fonts all come out of the vanilla menus[/*]
[*]Sounds like the menu it sits in: hover, confirm, cancel and refusal all play the game's own interface triggers. No sound file ships with the mod[/*]
[*]Full localisation in all 16 languages the game ships with[/*]
[*]Small footprint: a few kilobytes of interface data and one plugin. No vanilla file is replaced[/*]
[/list]
[size=6][b]What it writes[/b][/size]
The name lives in the description header of the [i].whs[/i] file, in the field the load list reads. The original goes into an attribute of its own, which is what [b]Del[/b] reads back:

[code]Before   UIDescription="…|@qname_predanivchramu_CiLb|@jmena_obj_zacatek_questu|…"

After    RenamerOriginal="@qname_predanivchramu_CiLb|@jmena_obj_zacatek_questu"
         UIDescription="…|Before the hard fight||…"[/code]
The quest name and the objective printed under it (if it exist via "-" symbol) both go into the stash, and the objective is cleared: a name you chose stands for the whole line, not half of it.

Nothing else in the file is touched, and the save data itself is copied through byte for byte. The write goes to a temporary file and replaces the original only once complete, so an interrupted write cannot leave you with half a savegame.

[size=6][b]Playlines[/b][/size]
A playline cannot be given a name of its own. The game rebuilds that heading from a template every time the menu opens, and a playline is only a folder of saves with nowhere to keep one.

The line underneath it is another matter: it is the quest name of that playline's most recent save, which is the very field this mod rewrites. Rename the newest save in a playline and the [i]Select Playline[/i] screen carries your text. Not a real name for the playthrough, but it labels the slot.

[size=6][b]Languages[/b][/size]
Czech, English, French, German, Italian, Spanish, Portuguese, Polish, Russian, Ukrainian, Turkish, Japanese, Korean, Simplified and Traditional Chinese, and Vietnamese — every language the game ships with.

Accept, cancel and reset are not translated by this mod at all: they are taken from the game's own strings, so they read exactly as they do everywhere else in your menu, and they follow it if Warhorse ever changes the wording.

[size=6][b]Uninstalling[/b][/size]
Delete [i]Mods/savegame_renamer/[/i]. Renamed saves keep their names and load normally without the mod. If you want the original names back, reset them with [b]Del[/b] before you remove it.

[size=6][b]Compatibility[/b][/size]
No vanilla file is replaced: the dialog is its own interface element on its own layer, and the mod's two strings are added to the game's tables rather than overwriting anything in them. Nothing is written to a save until you rename one.

The mod does hook the load menu, so a mod that replaces the menu movie wholesale is the one thing that could get in its way.

[b][url=https://www.nexusmods.com/kingdomcomedeliverance2/mods/3488]Rename Your Savegame[/url][/b] does the same job, so pick one rather than running both: two mods writing the same field of the same header will not agree about what the original was.

[size=6][b]Known limitations[/b][/size]
[list]
[*][b]Keyboard only.[/b] F2 opens the dialog, and the name is typed into it. The game's own menus carry no text field anywhere, so there is no on-screen keyboard a controller could reach even once the dialog is up. A pad still moves the highlight; naming the save needs a keyboard.[/*]
[*][b]A name typed in one script may show as boxes under another language.[/b] The game loads only the glyphs its current interface needs — under a European language it carries no Chinese, Japanese or Korean glyphs at all, and under a Chinese one the Latin font is cut down to 48 characters. Your name is stored correctly either way and reads properly again once you switch back. A mod cannot fix this without shipping a font of its own.[/*]
[*][b]Confirming a name you have not edited does nothing on purpose.[/b] A save you have never renamed holds a quest key rather than text, and the list translates it fresh in whatever language you play in. Writing that translation into the file would tie the save to one language, so the mod leaves it alone until you actually edit the name.[/*]
[*]The counter turns amber past 40 characters, and stays quiet while the field still holds the name it opened on. That is a hint rather than a limit: longer names are written and the list scrolls them. The field itself stops taking input at 120.[/*]
[/list]
