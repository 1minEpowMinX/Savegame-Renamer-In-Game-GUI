[size=6][b]Short description[/b][/size]
Rename any savegame from the game's own load menu. Highlight a save, press F2, type a name. No console, no external tools, and the list updates on the spot.

[size=6][b]The problem[/b][/size]
Your saves are named after the quest that was running when you made them, and nothing else. Play one questline for an evening and the load list turns into six rows reading [i]On the Guild's Business[/i], separated only by a timestamp. There is no way to mark the one before the hard fight, the one you want to come back to, or the one you keep for a different ending.

The information you want is already in the file. It just isn't yours to write.

[size=6][b]Main features[/b][/size]
[list]
[*][b]F2[/b] on the highlighted save opens a rename dialog. The key does nothing anywhere else in the menu[/*]
[*][b]Enter[/b] accepts, [b]Esc[/b] cancels, [b]Del[/b] puts the original name back. Every prompt is clickable too[/*]
[*]The load list redraws immediately, without leaving the page and coming back[/*]
[*]The original quest name is kept inside the save, so a rename is never one-way[/*]
[*]Built from the game's own artwork: the window frame, the key plates and the fonts all come out of the vanilla menus[/*]
[*]Full localisation in all 16 languages the game ships with[/*]
[*]Small footprint: a 5 KB pak and a plugin. No vanilla file is replaced[/*]
[/list]

[size=6][b]What it writes[/b][/size]
The name lives in the description header of the [i].whs[/i] file, in the field the load list reads. The original goes into an attribute of its own, which is what [b]Del[/b] reads back:

[code]
Before   UIDescription="…|@qname_predanivchramu_CiLb||…"

After    RenamerOriginal="@qname_predanivchramu_CiLb|"
         UIDescription="…|Before the hard fight||…"[/code]

Nothing else in the file is touched, and the save data itself is copied through byte for byte. The write goes to a temporary file and replaces the original only once complete, so an interrupted write cannot leave you with half a savegame.

Uninstalling is safe. Renamed saves keep their names and load normally without the mod. If you want the original names back, reset them with [b]Del[/b] before uninstalling.

The localisation covers Czech, English, French, German, Italian, Spanish, Portuguese, Polish, Russian, Ukrainian, Turkish, Japanese, Korean, Simplified and Traditional Chinese, and Vietnamese. Accept, cancel and reset are not translated by this mod at all: they are taken from the game's own strings, so they read exactly as they do everywhere else in your menu.

[size=6][b]Requirements[/b][/size]
[list]
[*][url=https://www.nexusmods.com/kingdomcomedeliverance2/mods/3332]Kingdom Come Script Extender[/url][/*]
[*][url=https://www.nexusmods.com/kingdomcomedeliverance2/mods/3381]Address Library For KCSE[/url], matching your game build[/*]

No new game required. Built and tested on 1.5.6. The Address Library is what maps the plugin to your particular build, so [b]update it after a game patch[/b]: a plugin asking for an address the table does not cover fails outright rather than quietly.

[size=6][b]Compatibility[/b][/size]
No vanilla file is replaced. The dialog is its own interface element on its own layer, so it does not collide with menu or HUD mods. Nothing is written to a save until you rename one.

[b]Rename Your Savegame[/b] does the same job, so pick one rather than running both: two mods writing the same field of the same header will not agree about what the original was.

[size=6][b]Known limitations[/b][/size]
[list]
[*][b]A name typed in one script may show as boxes under another language.[/b] The game loads only the glyphs its current interface needs — under a European language it carries no Chinese, Japanese or Korean glyphs at all, and under a Chinese one the Latin font is cut down to 48 characters. Your name is stored correctly either way and reads properly again once you switch back. A mod cannot fix this without shipping a font of its own.[/*]
[*][b]Confirming a name you have not edited does nothing on purpose.[/b] A save you have never renamed holds a quest key rather than text, and the list translates it fresh in whatever language you play in. Writing that translation into the file would tie the save to one language, so the mod leaves it alone until you actually edit the name.[/*]
[*]The character counter turns amber past 40 characters. That is a hint, not a limit: longer names are written, and the list scrolls them.[/*]
[/list]
